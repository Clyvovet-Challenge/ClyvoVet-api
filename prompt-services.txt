Continuando o projeto ClyvoVet.Api. Models, Enums, DTOs e Repositories já estão criados.
Agora vamos criar as interfaces e implementações dos Services. Não mexa em nada que já existe — apenas adicione.

Os Services são responsáveis por:
- Receber DTOs de Request
- Chamar os Repositories
- Mapear entidades para DTOs de Response
- Aplicar regras de negócio (validações, lógica)
- Lançar exceções quando necessário

ETAPA 3 — IMPLEMENTAÇÕES em Services/
=====================================================================

--- ProdutoService.cs ---

Recebe IProdutoRepository via construtor.

GetAllAsync:
- Chama repository.GetAllAsync com os filtros e paginação
- Mapeia cada Produto para ProdutoResponse
- Retorna a lista

GetByIdAsync:
- Chama repository.GetByIdAsync
- Se retornar null: throw new NotFoundException($"Produto com id {id} não encontrado.")
- Mapeia e retorna ProdutoResponse

CreateAsync:
- Mapeia ProdutoRequest para entidade Produto
- Chama repository.CreateAsync
- Mapeia resultado para ProdutoResponse e retorna

UpdateAsync:
- Chama repository.GetByIdAsync para verificar existência
- Se null: throw new NotFoundException($"Produto com id {id} não encontrado.")
- Mapeia ProdutoRequest para entidade Produto
- Chama repository.UpdateAsync
- Mapeia e retorna ProdutoResponse

DeleteAsync:
- Chama repository.DeleteAsync
- Se retornar false: throw new NotFoundException($"Produto com id {id} não encontrado.")

--- SugestaoProdutoService.cs ---

Recebe ISugestaoProdutoRepository e IAnimalRepository via construtor.

GetAllAsync:
- Chama repository com filtros e paginação
- Mapeia para SugestaoProdutoResponse incluindo NomeAnimal e NomeProduto

GetByIdAsync:
- Se null: throw new NotFoundException($"Sugestão com id {id} não encontrada.")
- Mapeia e retorna

CreateAsync:
- Valida se o AnimalId existe chamando animalRepository.GetByIdAsync
- Se não existir: throw new NotFoundException($"Animal com id {request.AnimalId} não encontrado.")
- Mapeia request para entidade SugestaoProduto
- Se DataSugestao não informada: usa DateOnly.FromDateTime(DateTime.Today)
- Chama repository.CreateAsync
- Mapeia e retorna SugestaoProdutoResponse

UpdateAsync:
- Verifica existência da sugestão
- Se null: throw new NotFoundException($"Sugestão com id {id} não encontrada.")
- Mapeia e atualiza
- Retorna SugestaoProdutoResponse

DeleteAsync:
- Se false: throw new NotFoundException($"Sugestão com id {id} não encontrada.")

--- LembreteService.cs ---

Recebe ILembreteRepository e IAnimalRepository via construtor.

GetAllAsync:
- Chama repository com filtros e paginação
- Mapeia para LembreteResponse incluindo NomeAnimal

GetByIdAsync:
- Se null: throw new NotFoundException($"Lembrete com id {id} não encontrado.")
- Mapeia e retorna

CreateAsync:
- Valida se AnimalId existe chamando animalRepository.GetByIdAsync
- Se não existir: throw new NotFoundException($"Animal com id {request.AnimalId} não encontrado.")
- Valida se AgendadoEm não está no passado
- Se estiver: throw new BadRequestException("A data do lembrete não pode ser no passado.")
- Mapeia request para entidade Lembrete
- Chama repository.CreateAsync
- Mapeia e retorna LembreteResponse

UpdateAsync:
- Verifica existência
- Se null: throw new NotFoundException($"Lembrete com id {id} não encontrado.")
- Mapeia e atualiza
- Retorna LembreteResponse

DeleteAsync:
- Se false: throw new NotFoundException($"Lembrete com id {id} não encontrado.")

--- EventoPetService.cs ---

Recebe IEventoPetRepository via construtor.

GetAllAsync:
- Chama repository com filtros e paginação
- Mapeia para EventoPetResponse

GetByIdAsync:
- Se null: throw new NotFoundException($"Evento com id {id} não encontrado.")
- Mapeia e retorna

CreateAsync:
- Valida se DataInicio não está no passado
- Se estiver: throw new BadRequestException("A data de início do evento não pode ser no passado.")
- Se DataFim informada e for anterior à DataInicio: throw new BadRequestException("A data de fim não pode ser anterior à data de início.")
- Mapeia request para entidade EventoPet
- Chama repository.CreateAsync
- Mapeia e retorna EventoPetResponse

UpdateAsync:
- Verifica existência
- Se null: throw new NotFoundException($"Evento com id {id} não encontrado.")
- Valida DataInicio e DataFim igual ao CreateAsync
- Mapeia e atualiza
- Retorna EventoPetResponse

DeleteAsync:
- Se false: throw new NotFoundException($"Evento com id {id} não encontrado.")

ETAPA 5 — MIDDLEWARE DE EXCEÇÕES no Program.cs
=====================================================================

Adicione um middleware global para tratar as exceções customizadas antes do app.Run():

app.UseExceptionHandler(errorApp =>
{
    errorApp.Run(async context =>
    {
        var exception = context.Features.Get<IExceptionHandlerFeature>()?.Error;

        context.Response.ContentType = "application/json";

        context.Response.StatusCode = exception switch
        {
            NotFoundException => StatusCodes.Status404NotFound,
            BadRequestException => StatusCodes.Status400BadRequest,
            _ => StatusCodes.Status500InternalServerError
        };

        var message = exception switch
        {
            NotFoundException e => e.Message,
            BadRequestException e => e.Message,
            _ => "Erro interno no servidor."
        };

        await context.Response.WriteAsJsonAsync(new { error = message });
    });
});

Adicione também no Program.cs antes do middleware acima:
builder.Services.AddExceptionHandler<>() não é necessário — use apenas o UseExceptionHandler acima.
